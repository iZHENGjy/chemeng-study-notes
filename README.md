## 笔记长什么样 / What a note looks like

**讲义笔记（L）**
- **本节定位**：这一讲在整门课里的位置、前置知识、后续用在哪
- **知识结构图**（Mermaid）：一眼看清概念之间的关系
- **知识块讲解**：每个概念先讲它解决什么问题，再给公式；公式带物理意义和单位，课件例题算到数值
- **讲义勘误**：课件里发现的笔误、数据前后不一致
- **延伸（非 PPT 内容）**：课件之外补充的背景和联系
- **对比与总结、我的疑问**：容易混的概念对照，没想通的地方留着问老师或查书

**习题详解（T）**
- 每道题逐步解到数值，带公式速查、所用数据与常数、答案速查
- **知识盲区**：做题暴露出来的薄弱点
